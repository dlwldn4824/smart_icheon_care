# 현수막 탐지 및 불법 가능성 판정 설계

CCTV만으로 “불법 현수막”을 확정할 수 없습니다. 카메라는 현수막의 **존재·위치**를 보고, 허가·게시 기간·설치 위치 등 **행정정보**와 결합해야 불법 가능성을 산정할 수 있습니다.

## 한 문장 정의

기존 CCTV와 공공데이터를 결합해 불법 현수막 **후보**를 자동 탐지하고, 한정된 행정 인력이 어떤 현수막부터 처리해야 하는지 제안하는 AI 행정 의사결정 지원 시스템입니다.

## 2단계 구조

1. **컴퓨터 비전 기반 현수막 탐지** — YOLO 계열, MVP는 `banner` 1클래스
2. **공공데이터 기반 불법 가능성 판정** — 신고대장·게시대·보호구역·민원 연계

```text
CCTV 영상
  → 프레임 추출 (1~2 fps)
  → 현수막 객체 탐지
  → ByteTrack 등 동일 객체 추적·통합
  → GPS·CCTV 위치 매핑
  → 현수막 신고대장·게시 기간 조회
  → 불법 가능성 점수
  → 철거·확인 우선순위
  → 공무원 최종 확인
```

## 점수 모델

### 불법 가능성 (Illegal Score)

```text
0.30 × 미허가 가능성
+ 0.25 × 부적절 위치
+ 0.20 × 게시 기간 만료
+ 0.15 × 보행·교통 방해
+ 0.10 × 반복 민원
```

| 점수 | 검토 단계 |
|------|-----------|
| 80+ | 긴급 확인 |
| 60–79 | 우선 확인 |
| 40–59 | 일반 확인 |
| &lt;40 | 관찰 |

표현은 반드시 **「불법 확정」이 아니라 「불법 가능성」**입니다.

### 행정 대응 우선순위 (Priority Score)

```text
0.35 × 불법 가능성
+ 0.25 × 안전 위험도
+ 0.15 × 보행량
+ 0.10 × 취약지역 가중치
+ 0.10 × 민원 빈도
+ 0.05 × 설치 지속 기간
```

취약지역 예: 어린이·노인보호구역, 교차로, 횡단보도, 버스정류장, 통학로, 사고 다발 지역.

## MVP 권장

| 항목 | 권장 |
|------|------|
| 탐지 클래스 | `banner` 단일 |
| 모델 | YOLO Small급 |
| 학습 데이터 | AI Hub 종합 민원 이미지 + 오탐 음성 샘플 |
| 데이터 분할 | CCTV/지역 단위 분리 (프레임 누수 방지) |
| OCR 검인 | MVP 제외, 고해상도 현장 사진에서만 보조 |
