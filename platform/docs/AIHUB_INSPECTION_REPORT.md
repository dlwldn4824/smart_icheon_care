## 2. TL1 / TS1 실제 클래스 (불법 현수막 아님)

압축 내부 1차 카테고리: **`보행방해물`만** 존재.

| 2차 클래스 | 대략 파일 수 |
|------------|-------------|
| 간이표지판(낮/밤) | 각 24,001 |
| **엑스배너(낮/밤)** | 각 24,001 |
| 간이의자(낮/밤) | 각 20,001 / 12,001 |
| 비활성에어간판(낮/밤) | 각 20,001 / 10,001 |
| 간이테이블(낮/밤) | 각 12,001 |
| 활성에어간판(낮/밤) | 각 10,001 / 12,001 |

**`가로현수막` / `세로현수막` / `불법 현수막` 폴더·클래스명: 0건**

즉 지금 받은 패키지는 AI Hub 종합 민원 중 **보행방해물(TS1/TL1)** 입니다.  
현수막 학습용 패키지(보통 별도 TS/TL 또는 현수막 카테고리 zip)를 추가로 받아야 합니다.

## 3. 실제 JSON 스키마 (추측 아님)

파일 예: `보행방해물/엑스배너(낮)/21_20210701_12635-0-1300.json`

```json
{
  "meta": {
    "Resolution": "1920x1080",
    "lat": 37.64,
    "lon": 126.83,
    "film_Time": "2021-07-01T00:00:00",
    ...
  },
  "annotations": {
    "Bbox Annotation": {
      "atchFileName": "21_20210701_12635-0-1300.jpg",
      "atchFilePath": "../../../원천데이터/보행방해물/엑스배너(낮)/",
      "Box": [
        {
          "category_id": 21,
          "category_name": "엑스배너(낮)",
          "x": 240.5,
          "y": 72.8,
          "w": 10.4,
          "h": 34.666...
        }
      ]
    }
  }
}
```

| 필드 | 의미 |
|------|------|
| `category_id` | 정수 ID (예: 엑스배너=21) |
| `category_name` | 한글 클래스명 |
| `x,y,w,h` | **저장 이미지 기준 픽셀** (실측 416×416). `meta.Resolution`(1920x1080)은 원본 CCTV 해상도이므로 normalize에 쓰지 않음 |
| 이미지 파일명 | `atchFileName` (라벨 stem과 동일) |

## 4. 사용자가 추가로 받을 것

AI Hub [종합 민원 이미지 AI데이터](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=492)에서:

```text
현수막 / 가로현수막(낮·밤) / 세로현수막(낮·밤)
원천데이터 + 라벨링데이터
```

받은 뒤 같은 위치에 두고:

```bash
python scripts/inspect_dataset.py --input datasets/raw/aihub_banner
python scripts/convert_aihub_to_yolo.py --input datasets/raw/aihub_banner --output datasets/banner
```

변환 시 프로젝트 클래스 매핑:

```text
가로현수막(*) / 세로현수막(*) / *현수막*  →  banner (id=0)
불법 현수막 원본명이어도 학습 클래스는 banner
```

## 5. 임시 대안 (권장하지 않음)

현재 데이터만으로 파이프라인을 돌리려면 `--include-xbanner`로 **엑스배너**를 `banner`로 매핑할 수 있으나,  
도로 가로·세로 현수막과 형태가 달라 **본학습 대용으로 쓰면 안 됩니다.**
